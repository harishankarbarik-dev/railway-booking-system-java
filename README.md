# 🚆 Railway Ticket Booking System - Java

A full-stack Railway Ticket Booking System built with **Java Spring Boot**.
Users can Signup, Login, Search Trains, Book Tickets and View Booking History.

🔗 **Live Demo:** Run locally on `http://localhost:8080`

---

## ✨ Features

- **User Authentication** - Signup / Login / Logout with validation
- **Ticket Booking** - Book tickets with From, To, Date, Passenger details
- **Booking History** - View all booked tickets
- **Validation** - Prevents same source & destination, duplicate user, wrong login
- **Error Handling** - Custom error pages for User Exists, Wrong Password, etc.
- **Responsive UI** - Clean HTML / CSS pages for Booking, Login, Signup

## 🛠️ Tech Stack

- **Backend:** Java 17, Spring Boot, Spring MVC, Spring Data JPA
- **Frontend:** HTML, CSS, Thymeleaf
- **Database:** H2 / MySQL
- **Build Tool:** Maven
- **IDE:** Eclipse / VS Code
